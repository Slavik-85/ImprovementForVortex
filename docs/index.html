Features

Built to feel like it shipped with the site

Every feature below runs directly on playvortex.io's own pages - no separate app, no extra tab.

Pinning & playtime

Pin it. Track it. Never lose it.

Pin your favorite games straight from the grid - they get their own row on your home page. Every time you hit Play, IFV quietly tracks how long you've actually spent in that game, right there on the card.

Toolbar popup

Your whole toolkit, one click.

Every feature toggle, your theme settings, and your full pinned-games list - all in one popup that lives in your toolbar. Nothing to dig for, nothing buried in a settings page.

Server browser

A server list that works for you.

Search a server by nickname, hide the ones that are full, or auto-join the least (or most) full one in a single click. Vortex shows you the list - IFV makes it useful.

Theme creator

Make it actually yours.

Vortex only ever shipped one look. Flip to a full light mode, or pick your own accent, background, surface, and text colors - applied everywhere, instantly.

And the rest

Six more small upgrades

Live player counts

Game cards and detail pages update in the background - no refresh needed.

Quick play & prefetch

Hover a card and the next page is already loading before you click.

Surprise me

Join a friend

Dynamic greetings

Zero setup

Get started

Install it in under a minute

Not on the Chrome Web Store yet - for now, load it unpacked like a developer.

Download or git clone this repository to your computer.

Open chrome://extensions and turn on Developer mode (top right).

Click Load unpacked and select the project folder.

Visit playvortex.io - IFV is already running.

No tracking. No data collection.

Everything IFV stores - pins, playtime, theme, settings - lives only in your own browser. Nothing is ever sent to us or anyone else. Read the full privacy policy.
